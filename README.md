# 나만의 행성 공방

PC와 Android 태블릿에서 3D 행성 표면을 직접 칠하는 웹앱입니다. 별과 성운이 있는 우주 배경, 고리, 최대 8개 위성, 조명, 자동 기억을 지원합니다. 외부 라이브러리·이미지·로그인·서버 없이 실행합니다.

## GitHub Pages에 올리기

1. ZIP 압축을 풀어 주세요.
2. GitHub에서 새 저장소를 만드세요. 무료 계정으로 Pages를 사용할 때는 공개(Public) 저장소를 선택하세요.
3. 저장소의 **Add file → Upload files**를 누르세요.
4. 압축 안의 `index.html`, `style.css`, `app.js`, `gif-worker.js`, `.nojekyll`, `README.md`를 저장소 최상위에 올리고 Commit changes를 누르세요. ZIP 자체를 올리는 방식이 아닙니다. `index.html`이 저장소 첫 화면에 보여야 합니다.
5. **Settings → Pages → Build and deployment**에서 **Deploy from a branch**를 선택하세요.
6. Branch는 `main`, 폴더는 `/ (root)`로 정하고 Save를 누르세요.
7. 배포가 끝나면 Pages 화면의 사이트 주소로 접속하세요. 주소 형식은 `https://사용자명.github.io/저장소명/`입니다.

Vercel에서는 같은 저장소를 가져오고 Framework Preset을 Other로 선택해 정적 사이트로 배포할 수 있습니다. 별도 빌드 명령은 필요하지 않습니다.

## 학생 사용 방법

- **행성 위에서 한 손가락 또는 마우스 드래그:** 색칠
- **행성 바깥에서 시작한 드래그:** 행성 회전, 뒷면 보기
- **두 손가락 벌리기/모으기 또는 마우스 휠:** 확대/축소
- **정면 보기:** 시점과 확대를 처음으로 돌리기
- 태블릿은 가로 화면을 권장합니다. 작은 화면에서는 **도구** 버튼으로 도구를 열고 닫습니다.

### 붓

종류별 9색 견본과 직접 고르기, 크기·진하기·부드러움·거칠기를 조절합니다. 스포이드를 선택한 다음 행성 표면을 누르면 그 지점의 원래 색을 가져옵니다. 낮·밤 조명에 따른 어두운 색은 스포이드에 포함되지 않습니다.

‘행성 전체 채우기’로 선택한 색을 전체에 칠합니다. 되돌리기는 드래그 한 번 또는 설정 변경을 한 단계로 기록하고 최대 6단계까지 가능합니다. 키보드 Ctrl+Z 또는 Mac Cmd+Z도 지원합니다. 행성 이름 입력 중에는 일반 텍스트 되돌리기가 적용됩니다. 작업을 다시 열면 되돌리기 이력은 초기화됩니다.

### 표면

암석형은 표면 요철을 빛과 그림자로 표현합니다. **실제 구체의 외곽 모양을 변형하는 방식은 아닙니다.** 무늬 촘촘함을 낮추면 큰 요철 무늬가 됩니다. 반짝임도 조절합니다.

가스형은 붓을 가로로 펼칩니다. 붓 탭의 ‘옆으로 문지르기’를 켜고 칠한 색 위를 움직이면 색이 가로 방향으로 섞입니다. 종류를 바꿔도 기존 색칠은 유지됩니다. 은은한 자체 발광은 상상 표현으로 기본값은 0입니다.

### 대기·고리·위성

대기 빛의 색, 밝기, 넓이를 조절합니다. 고리의 거리·넓이·기울기·진하기·틈 무늬를 바꿀 수 있습니다. 넓은 띠와 굵은 틈, 잔잔한 동심원 무늬를 표현하며 양면 조명을 적용했습니다. 고리 기울기는 면이 보이는 각도를 조절합니다. 기존 작품의 고리가 어색하면 고리 탭의 **‘토성 고리 모양으로’** 버튼을 눌러 주세요. 기존 행성 색칠은 유지됩니다. 위성은 최대 8개이며 번호를 눌러 하나씩 색·크기·거리·속도·궤도 기울기를 조절합니다. 위성 궤도는 원형입니다.

### 빛·회전

자동 회전은 처음에 꺼져 있습니다. ‘저절로 돌기’를 누르면 행성 자전과 위성 공전이 시작됩니다. 색칠하거나 화면을 직접 조작하는 동안에는 움직임이 잠시 멈춥니다. ‘모두 멈추기’를 누르면 움직임 전체가 정지하고 바깥 드래그로 수동 회전은 가능합니다. 고리는 행성의 기울기와 수동 회전을 함께 따릅니다. 동심원 모양이라 자전에 따른 회전 차이는 드러나지 않습니다.

햇빛의 좌우·위아래 방향과 밝기를 조절하면 밝은 낮과 어두운 밤을 볼 수 있습니다. 배경 별은 끌 수 있으며 성운 배경은 유지됩니다.

## 저장

- **PNG 저장:** 현재 시점에서 보이는 행성·고리·위성·우주 배경을 행성 이름과 함께 1600×1000 이미지로 저장합니다. 뒷면까지 한 장에 펼치는 방식은 아닙니다.
- **회전 GIF:** 현재 시점과 조명으로 행성이 한 바퀴 도는 **6초 반복 GIF**를 저장합니다. 480×300, 50프레임(약 8fps)이며 위성도 설정 속도에 비례해서 움직입니다. GIF의 256색 특성상 PNG보다 색과 움직임이 단순해 보일 수 있습니다. GIF는 별도 스레드에서 변환하며 취소할 수 있습니다. GitHub Pages 같은 배포 주소에서 사용하세요.
- **회전 영상:** 같은 회전 장면을 **6초, 1280×800, 최대 30fps**로 녹화합니다. Chrome/Edge에서는 일반적으로 WebM을 사용하고, 브라우저가 지원하면 MP4를 사용합니다. MP4를 지원하지 않으면 WebM으로 저장합니다. 음성은 들어가지 않습니다. 영상 기능이 없으면 GIF 사용 안내가 나옵니다.
- GIF·영상 모두 행성은 한 바퀴 돌아가도록 저장하며, 행성 도는 속도 설정은 위성 속도의 상대 비율에 반영됩니다. 고리는 기울기와 형태를 유지합니다. 저장 중에는 작업 도구가 잠기고 저장이 끝나거나 취소되면 원래 방향과 자동 회전 상태로 돌아옵니다. 창을 이동하면 저장이 중단됩니다. 영상 저장은 실제 6초 동안 진행됩니다. GIF 생성 시간은 기기에 따라 다릅니다.
- **자동 기억:** 같은 기기, 같은 브라우저, 같은 사이트 주소에서 마지막 색칠과 설정을 이어갑니다. 변경 후 약 0.7초 뒤 기기 내부 IndexedDB에 저장합니다. 저장 완료 표시를 확인하고 창을 닫아 주세요.
- **작업 저장:** 모든 방향의 색칠과 설정을 `.planet.json` 파일로 저장합니다. 다른 기기에서 ‘작업 불러오기’로 이어갈 수 있습니다. 수업 종료 때 이 파일을 저장하면 작품 보관에 편리합니다.
- 시크릿 모드, 브라우저 데이터 삭제, 기기 변경, 사이트 주소 변경 시 자동 기억을 유지하지 못할 수 있습니다. 자동 기억이 안 될 때는 하단에 안내가 표시됩니다.
- 학생 작품은 서버로 전송되지 않습니다. 교사에게 제출하려면 PNG 또는 작업 파일을 별도로 공유하세요.

## 실행 환경과 확인 범위

WebGL을 지원하는 최신 Chrome/Edge/Safari가 필요합니다. WebGL이 꺼져 있으면 안내 메시지를 보여 줍니다. PC에서는 파일을 직접 열 수도 있지만 자동 기억은 배포된 HTTPS 주소에서 사용하는 것이 안정적입니다.

코드 구문, 초기화, 구체 표면 감지, 좌우 경계와 극지방 색칠, 되돌리기 복원/최대 6단계, 작업 파일 검증 및 실제 OpenGL ES 2 셰이더 컴파일·링크를 확인했습니다. GIF 파일을 생성해 모든 프레임을 이미지 디코더로 읽고 반복 설정과 6초 구성의 프레임 시간을 검증했습니다. 저장 후 원래 행성·위성 방향 복원과 영상 미지원 안내도 코드 검사로 확인했습니다. 수정된 고리는 실제 OpenGL ES 렌더링 이미지로 형태와 앞뒤 가림을 확인했습니다. 실제 브라우저의 MediaRecorder 영상 출력, 화면과 갤럭시탭 터치 조작은 이번 제작 환경에서 검증하지 못했습니다. 수업 전 배포 주소에서 색칠 → 회전 → 두 손가락 확대 → PNG 저장 → 새로고침 후 복원 순서로 확인해 주세요.

## 파일 구성

- `index.html`: 화면 구조
- `style.css`: PC/태블릿/모바일 반응형 디자인
- `app.js`: WebGL 렌더링, 붓, 꾸미기, PNG/GIF/영상 및 작업 저장
- `gif-worker.js`: GIF 파일 생성
- `.nojekyll`: GitHub Pages 정적 파일 처리

수정한 뒤 같은 파일을 GitHub에 다시 올리면 됩니다. 태양·행성의 실제 크기나 궤도 속도를 재현하는 시뮬레이터가 아니라 창작용 도구입니다.
